# Bundled font

**Baloo 2** — variable weight (400–800), latin subset only.

- Source: Google Fonts (https://fonts.google.com/specimen/Baloo+2)
- Licence: SIL Open Font License 1.1, see `OFL.txt`

Self-hosted rather than linked from Google's CDN so the app works on a
LAN with no internet, and so no player's browser calls out to a third
party mid-game. Only the latin subset is included; the upstream family
also covers Devanagari and Vietnamese.
